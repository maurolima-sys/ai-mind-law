# Tech — AI Mind Law

## Languages & Runtime
- TypeScript 5.8 (strict mode, ES2022 target)
- React 19
- Node.js (npm) or Bun as package manager

## Framework & Build
| Tool | Version | Role |
|------|---------|------|
| TanStack Start | 1.168.x | Full-stack React framework (SSR + file-based routing) |
| TanStack Router | 1.170.x | Type-safe file-based routing |
| Vite | 8.1.5 | Dev server and bundler |
| Nitro | 3.x beta | SSR server (Cloudflare Workers target by default) |
| @lovable.dev/vite-tanstack-config | 2.27.2 | Opinionated Vite preset (do not duplicate its plugins) |

## UI
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- shadcn/ui "new-york" style, slate base color, CSS variables enabled
- Radix UI primitives (full suite)
- Lucide React icons
- Recharts for data visualisation
- `class-variance-authority` + `clsx` + `tailwind-merge` for variant styling

## State & Data
- TanStack Query v5 — async/server state
- React Hook Form v7 + Zod v3 — form validation
- Vercel AI SDK (`ai` v7, `@ai-sdk/openai` v4) — AI streaming (not yet wired to UI)

## Document Processing
- `pdfjs-dist` v6 — browser-side PDF text extraction

## Testing
- Vitest v4 (jsdom environment, globals enabled)
- @testing-library/react v16 + @testing-library/jest-dom v6
- Test files: `src/**/*.{test,spec}.{ts,tsx}`
- Setup file: `src/test/setup.ts`

## Linting & Formatting
- ESLint 9 flat config (`eslint.config.js`)
  - typescript-eslint recommended
  - react-hooks recommended
  - react-refresh (warn on non-component exports)
  - Prettier integrated via `eslint-plugin-prettier`
  - `server-only` import banned (use `*.server.ts` or TanStack Start's server-only marker instead)
- Prettier: printWidth 100, semi true, double quotes, trailing commas

## TypeScript Strictness (tsconfig.json)
- `strict: true`
- `noImplicitReturns`, `noImplicitOverride`, `noFallthroughCasesInSwitch`
- `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`
- Path alias: `@/*` → `./src/*`

## Development Commands
```sh
npm run dev          # Start dev server
npm run build        # Production build
npm run build:dev    # Development build
npm run preview      # Preview production build
npm run lint         # ESLint check
npm run format       # Prettier write
npm test             # Vitest run (single pass)
npm run test:watch   # Vitest watch mode
```

## Key Config Files
- `vite.config.ts` — minimal; delegates to `@lovable.dev/vite-tanstack-config`; sets SSR entry to `src/server.ts`
- `components.json` — shadcn/ui CLI config
- `bunfig.toml` — Bun-specific config
- `routeTree.gen.ts` — auto-generated by TanStack Router plugin; never edit manually
